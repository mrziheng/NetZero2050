# Public Linear Programming Problem Instance for the GISPO Model

## Overview

This repository contains:

a. source data and code for plotting results as reported in the article manuscript [**Integrated Planning of Net-Zero Power Systems for All**](https://www.researchsquare.com/article/rs-7265214/v1).

b. guidance for how to run the standalone Linear Programming (LP) problem files generated by the **Global Integrated Sustainable Power-system Optimization (GISPO)** model, stored in Zenodo (https://doi.org/10.5281/zenodo.17618090). These files correspond to the "Base Scenario" analyzed in the research article manuscript [**Integrated Planning of Net-Zero Power Systems for All**](https://www.researchsquare.com/article/rs-7265214/v1).

c. power demand profiles for each grid modeled in the GISPO model.

It contains the LP problem files for all power regions in the base scenario of the global power just transition study using GISPO. As stated in the paper, GISPO solves the problem by partitioning it into sub-regions based on the power grid topology. Therefore, the folder includes `partial_x.lp` files (where x is from 0 to 8, 0 for the world and 1st to 8 for each of the 9th sub-regions). These files can be solved using the read function of a solver.

## 1. System Requirements

To reproduce the results by solving these LP files, the following hardware and software environments are required.

### Hardware Requirements

- **RAM:**  16GB RAM is required to load the smaller instances (e.g., `partial_8.lp`). For the largest full-scale instances (e.g., `partial_0.lp`, 31.9 GB), a higher-performance server with at least 2000 GB RAM and 196 cores is recommended to solve it. Attempting to load `partial_0.lp` on a standard laptop may result in a memory crash and is therefore not suggested.
- **Disk Space:** At least 100 GB of free space to store the unzipped LP files and solution outputs.
- **Processor:** A multi-core processor is recommended for parallel barrier solving.

### Software Dependencies

- **Operating System:** Windows 10/11, Linux (Ubuntu 20.04+ recommended), or macOS.
- **Python:** Version 3.9 +
- **Solver:** While the files adhere to the standard `.lp` format and can theoretically be read by open-source solvers (e.g., CBC, GLPK), a commercial-grade LP solver is recommended due to the scale of the problem. We utilized **Gurobi Optimizer version 10.0**.
- **Python Libraries:**
  - `gurobipy` (or the equivalent Python API for your chosen solver)

## 2. Installation Guide

### Setting up the Environment

1. **Install Python:** Download and install Python from [python.org](https://www.python.org/).
2. **Install Solver:** Ensure your solver (e.g., Gurobi) is installed, and a valid license is active. For Gurobi, see [official tutorial](https://support.gurobi.com/hc/en-us/articles/360044290292-How-do-I-install-Gurobi-for-Python) for installation of python interface.

## 3. Demo: Instructions to Run

To demonstrate the reproducibility of the model, **we strongly recommend starting with the smallest instance (`partial_8.lp`, ~398 MB)** to verify the environment and solver configuration.

### Steps to Run the Demo

1. Download and unzip the `GISPO_LP.zip` archive from this repository.

2. Ensure the provided Python script `solve_gispo_lp.py` is placed in the same directory as the `GISPO_LP` folder (or adjust the path accordingly).

3. Run the script via terminal/command prompt:

   ```
   # Option 1: Run the default demo (targets partial_8.lp)
   python solve_gispo_lp.py
   
   # Option 2: Specify a path to a specific file
   python solve_gispo_lp.py GISPO_LP/partial_8.lp
   ```

### Expected Output

The solver will output the log detailing the pre-solve, iteration process (Barrier/Simplex), and final objective value.

- **Expected Status:** `Optimization was successful` (or `Optimal`).
- **Expected Run Time:**
  - For `partial_8.lp` (Demo): Approximately 20 minutes on a standard desktop.
  - For `partial_0.lp` (Full Scale): This requires a high-performance server, and running on a standard desktop may cause a memory crash.

## 4. Instructions for Use (Source Code & Custom Data)

The `.lp` files in this archive are static snapshots of the model instances used in the paper. To generate new LP files with different parameters, inputs, or for other regions, please refer to our source code and data generation repositories.

### Source Code Repositories

Other Python source code for plotting and data processing of the relevant research article manuscript is available at:

- **LP Files:** https://doi.org/10.5281/zenodo.17618090
- **Data Generation:** https://github.com/mrziheng/GlobalRenewableEnergyResource

### Reproduction Instructions

1. Clone the `NetZero2050` repository.
2. Follow the instructions in that repository's README to set up the input data (downloaded from the `GlobalRenewableEnergyResource` repo).
3. Run the main model script (e.g., `run_gispo_main.py`) to generate new `.lp` files.
4. Solve the generated files using the method described in the "Demo" section above.
